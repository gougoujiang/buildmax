# 会议/日程示例数据 (Meetings)

用于冲突检测、某人日程、会议室占用等演示。

## 文件

| 文件 | 说明 |
|------|------|
| `meetings.csv` | 会议表：开始、结束、会议室、参与人、主题、时长(分) |

## 字段

- **start_time**: 开始时间
- **end_time**: 结束时间
- **room**: 会议室（会议室A、会议室B）
- **attendees**: 参与人（分号分隔）
- **title**: 会议主题
- **duration_min**: 时长（分钟）

## 示例查询

- 某人参与的所有会议（grep attendees）
- 某会议室某时段是否占用（时间区间重叠）
- 按日期或会议室筛选
- 会议时长统计
