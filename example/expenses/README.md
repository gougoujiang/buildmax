# 记账/开支示例数据 (Expenses)

用于按分类/月度汇总、支出趋势、账户统计等演示。

## 文件

| 文件 | 说明 |
|------|------|
| `expenses.csv` | 开支表：日期、分类、金额、账户、备注 |

## 字段

- **date**: 日期
- **category**: 分类（餐饮、交通、购物、住房、娱乐、学习、医疗、通讯等）
- **amount_cny**: 金额（元）
- **account**: 支付账户（支付宝、微信、银行卡、无）
- **note**: 备注

## 示例查询

- 按分类汇总金额
- 按日期范围或月份汇总
- 某账户支出合计
- 单笔大额（amount_cny 大于某值）
