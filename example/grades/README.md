# 学生成绩表示例数据 (Grades Example)

用于 Agent 工具（read_file, grep, editfile 等）的测试与演示。

## 文件说明

| 文件 | 说明 |
|------|------|
| `grades.csv` | 成绩明细：学号、姓名、班级、科目、分数、考试日期 |

## 字段说明

- **student_id**: 学号
- **name**: 姓名
- **class**: 班级（高一(1)班 / 高一(2)班）
- **subject**: 科目（语文、数学、英语、物理、化学）
- **score**: 分数 (0–100)
- **exam_date**: 考试日期

## 示例查询思路

- 按班级统计平均分、最高分
- 按科目找出不及格（&lt;60）学生
- 按学号汇总某学生的各科成绩与总分
- 按考试日期筛选
