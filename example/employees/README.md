# 员工/HR 示例数据 (Employees)

用于按部门、职位、工龄、薪资档位做统计与筛选演示。

## 文件

| 文件 | 说明 |
|------|------|
| `employees.csv` | 员工表：工号、姓名、部门、职位、入职日、薪资档位 |

## 字段

- **employee_id**: 工号
- **name**: 姓名
- **department**: 部门（研发、产品、设计、市场、人事）
- **position**: 职位
- **hire_date**: 入职日期
- **salary_band**: 薪资档位（A/B/C，A 最高）

## 示例查询

- 按部门统计人数
- 按职位或薪资档位筛选
- 工龄计算（基于 hire_date）
- 某部门下的员工列表
