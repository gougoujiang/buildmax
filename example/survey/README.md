# 问卷/调查示例数据 (Survey)

用于选项分布、多题交叉、完成率等演示。

## 文件

| 文件 | 说明 |
|------|------|
| `responses.csv` | 答卷表：答卷 id、题目 id、题目文本、选项、答卷人 |

## 字段

- **response_id**: 答卷记录 ID
- **question_id**: 题目 ID（Q1/Q2/Q3/Q4）
- **question_text**: 题目文本
- **option**: 所选选项（多选用分号分隔）
- **respondent**: 答卷人（可匿名）

## 示例查询

- 按题目统计各选项数量（分布）
- 某题的平均分（如 Q3 满意度）
- 多题交叉（如「选 Go 的人里选「是」的比例」）
- 完成率（按 respondent 去重计数）
