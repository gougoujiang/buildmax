# 健身/运动示例数据 (Fitness)

用于周/月汇总、运动类型分布、卡路里统计、目标完成率等演示。

## 文件

| 文件 | 说明 |
|------|------|
| `fitness.csv` | 运动记录：日期、运动类型、时长(分)、卡路里、备注 |

## 字段

- **date**: 日期
- **activity_type**: 运动类型（跑步、力量、游泳、骑行、瑜伽、休息）
- **duration_min**: 时长（分钟）
- **calories**: 消耗卡路里（估算）
- **note**: 备注

## 示例查询

- 按周/月汇总运动次数或总时长
- 按运动类型统计
- 卡路里合计或日均
- 休息日与训练日分布
