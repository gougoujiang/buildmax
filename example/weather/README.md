# 天气记录示例数据 (Weather)

用于城市对比、温度趋势、降水统计等演示。

## 文件

| 文件 | 说明 |
|------|------|
| `weather.csv` | 天气记录：日期、城市、最高温、最低温、降水(mm)、天气现象 |

## 字段

- **date**: 日期
- **city**: 城市（北京、上海、广州）
- **temp_max**: 最高气温（℃）
- **temp_min**: 最低气温（℃）
- **precipitation_mm**: 降水量（毫米）
- **conditions**: 天气现象（晴、多云、阴、小雨、中雨、雷阵雨）

## 示例查询

- 某城市某时段温度趋势
- 城市间温度或降水对比
- 有降水日筛选（precipitation_mm > 0）
- 按天气现象统计
