# 电影/影评示例数据 (Movies)

用于排行、类型分布、年度 Top N、评分筛选等演示。

## 文件

| 文件 | 说明 |
|------|------|
| `movies.csv` | 电影表：片名、类型、年份、评分、票房(亿元) |

## 字段

- **title**: 片名
- **genre**: 类型（科幻、剧情、喜剧、战争、动画、动作等）
- **year**: 上映年份
- **rating**: 评分（0-10）
- **box_office_cny_m**: 票房（单位：百万元，即亿元×100）

## 示例查询

- 按类型统计数量或总票房
- 按评分排序（高分/低分）
- 某年度电影列表或 Top N
- 票房过某阈值的电影
