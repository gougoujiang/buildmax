# 食谱/菜谱示例数据 (Recipes)

用于按食材查菜、按分类/难度筛选、烹饪时间排序等演示。

## 文件

| 文件 | 说明 |
|------|------|
| `recipes.csv` | 菜谱表：菜名、食材、分类、难度、烹饪时间(分) |

## 字段

- **dish_name**: 菜名
- **ingredients**: 主要食材（分号分隔）
- **category**: 分类（家常、川菜、粤菜、素菜、凉菜、主食）
- **difficulty**: 难度（easy / medium）
- **cook_minutes**: 烹饪时间（分钟）

## 示例查询

- 按食材查菜（grep 某食材）
- 按分类或难度筛选
- 快手菜（cook_minutes 小于某值）
- 按时间排序
