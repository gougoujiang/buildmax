# Task 095: Two-tier agent — Phase 5 (optional) — Task decomposition

Tier 1 can break one user request into multiple Tier 2 tasks (multiple ChatRuns). Optional phase; implement after Phases 1–4 are stable.

**Design:** [design/007-two-tier-agent.md](../design/007-two-tier-agent.md) §8 Phase 5.

**Deliverables:**
- Conversation engine (LLM path): when Tier 1 decides to decompose, it returns multiple task inputs (e.g. a list of messages or run params); server or engine creates multiple ChatRuns for the same chat (or linked runs), all PENDING; scheduler picks them up as today.
- Ordering/grouping: define whether runs are independent or ordered (e.g. run B after A); if ordered, scheduler or worker may need to wait for prior run completion (optional for this task).
- API/UX: portal (and optionally IM) shows multiple “sub-tasks” or run list for one user message; artifacts per run as today.
- Tests: at least one flow where one turn produces multiple runs with distinct inputs.

**Out of scope:** Complex DAG of tasks; cross-workspace decomposition.
