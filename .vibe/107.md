# Task 107: TUI status line refine

## Goal

Split the TUI footer from a single line into two lines, and show the logged-in user's email on the first line.

## Background

The current footer is rendered by `renderFooterView()` in `internal/interface/tui/model.go` as one line:

```
model: GPT-4o-mini | @/Users/.../buildmax (|-main) | ctrl+c: quit | esc: clear/focus input | opt+mouse: select text
```

The user wants a two-line footer with clearer separation between context info and keyboard shortcuts, plus the current user's identity.

## In scope

1. **Two-line footer layout**:
   - **Line 1** (context): `model: GPT-4o-mini | @/path (|-branch) | user@example.com`
   - **Line 2** (shortcuts): `ctrl+c: quit | esc: clear/focus input | opt+mouse: select text`
2. **User email in TUIOpts**: Add a `UserEmail` field to `TUIOpts`; populate it from stored credentials (`auth.Load(config.AuthPath())`) in `runTUI` (`internal/interface/cli/tui.go`).
3. **Graceful fallback**: If no credentials or email is available, omit the email segment from line 1 (no trailing `|`).
4. **Viewport sizing**: `syncViewportSize` already accounts for `footerHeight` via `lipgloss.Height(m.renderFooterView())`; since the footer now returns two lines, the viewport will shrink by one line automatically — no additional changes needed.

## Out of scope

- Showing user name instead of / in addition to email.
- Dynamic credential refresh or login-state change detection within a running TUI session.
- Any changes to the desktop or portal footer.

## Deliverables

- Modified `internal/interface/tui/model.go`: new `UserEmail` field on `TUIOpts`, updated `renderFooterView()`.
- Modified `internal/interface/cli/tui.go`: load credentials and pass `UserEmail` into `TUIOpts`.
- Existing tests still pass.

## Acceptance

- [ ] Footer renders as two lines when `UserEmail` is set: line 1 has model, workspace/branch, and email; line 2 has keyboard shortcuts.
- [ ] Footer renders as two lines when `UserEmail` is empty: line 1 has model and workspace/branch only (no trailing separator); line 2 has keyboard shortcuts.
