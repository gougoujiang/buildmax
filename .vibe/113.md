# Task 113: TUI builtin slash commands

## Goal

Let users type **`/…` commands** in the BuildMax Bubble Tea TUI as **system tools**: they are **not** chat turns (nothing is appended to the conversation session, nothing is sent to the LLM). Ship **`/mcp`** first: show the current MCP configuration as a **dedicated on-screen list** the user can read; **Esc** closes that view and returns to **normal input** (same as exiting a transient system UI).

## Context

- **TUI submit path**: `internal/tui/model.go` — on Enter with input focused and not `busy`, trimmed text is appended as a **user** `llm.Message` and `runAgentWithStream` runs. Slash commands must be handled **before** that path.
- **Workspace**: `TUIOpts.Workspace` matches CLI setup (`internal/cmd/cli/tui.go`); MCP config resolution must match the CLI: `config.LoadMCPConfigForWorkspace(workspaceDir)` — see `internal/config/mcp.go`.
- **MCP runtime**: `internal/app/agentrun/runtime.go` — when `EnableMCP` is true, `mcpservers.NewRegistry` is **fail-fast**. The registry is not exposed on `Runtime` today (`internal/mcpservers/registry.go`).
- **Principle**: Slash command output must **not** pollute `session` message history or the chat viewport transcript. Use **overlay / modal / full-width panel** state on the Bubble Tea model (or equivalent) for `/mcp`; chat `ViewportBlock` content stays unchanged when viewing the list.

## In scope

1. **Slash command dispatch (system only)**

   - When the user presses Enter and the trimmed input **starts with `/`**, treat it as a slash command (case-sensitive command names unless specified otherwise).
   - **Do not** `session.Append` the line as **user** or **assistant** (or any role). **Do not** call `PersistAfterReply` solely because of a slash command. **Do not** invoke the agent.
   - Clear the input after handling.
   - While `busy` (agent running), Enter behavior stays as today (ignore submit).
   - **Unknown** commands: show brief **non-chat** feedback only (e.g. set `m.err` for the footer line, or a one-line transient system message area) — **no** session append.

2. **`/mcp` (dedicated list UI)**

   - Entering `/mcp` opens a **system view** (overlay or dedicated pane) that lists MCP servers for the current workspace using `LoadMCPConfigForWorkspace(TUIOpts.Workspace)`.
   - **Load error**: show the error text **inside this system view** (or an empty list + error header), not as a chat message.
   - **No config / empty `mcpServers`**: show an explicit empty state in the same view (short copy + where to configure `mcp.json` if desired).
   - **Non-empty config**: list each server **id** in stable sorted order with **type** (`stdio` / `sse` / `http`) and **status** `connected` or `error: <reason>` from a **live probe** (same approach as before: per-server connect + list tools with bounded timeout, then close; stdio may briefly spawn a process). Optional: tool count when connected.
   - **Esc**: dismiss the MCP list, return to the normal chat + input layout with **focus on the input** (same expectation as “back to normal input state”).
   - While the MCP list is open, **Esc** must be handled by this overlay first (do not clear the input textarea as if it were the “clear input” Esc path unless the overlay is already closed).

3. **Tests**

   - Unit tests: slash detection does not append to session and does not schedule agent runs; `/mcp` toggles overlay state; Esc clears overlay and restores input focus.
   - `internal/mcpservers` probe tests: in-memory / existing patterns — no real network or external binaries in CI.

4. **Footer / discoverability (minimal)**

   - Extend `renderFooterView` with a short hint (e.g. `/mcp` — Esc to close when relevant), without implying slash output goes to chat.

## Out of scope

- Slash commands in **`-p` / prompt mode** (non-TUI) unless a follow-up task adds them.
- **Portal / desktop** UIs.
- Changing MCP **fail-fast** at `agentrun.Open` — optional follow-up; `/mcp` can still use per-server **probe** for status display.
- Additional slash commands beyond **`/mcp`** except unknown-command handling.
- Autocomplete or interactive picker for slash commands.

## Acceptance criteria

- [ ] Slash input is **never** a chat turn: no `session.Append` for the `/…` line or for slash command output; no LLM call.
- [ ] Normal messages without a leading `/` still go to the agent unchanged.
- [ ] `/mcp` opens a **dedicated list view** of MCP servers (ids, types, connected / error); chat history in the main viewport is **not** used for this list.
- [ ] **Esc** closes the MCP list and returns to normal operation with **input focused**.
- [ ] `/mcp` uses merged MCP config rules (`LoadMCPConfigForWorkspace` + TUI workspace).
- [ ] Unknown `/foo` shows non-chat feedback only; no agent call; no session append.
- [ ] `go test ./...` passes; new tests do not require network or real MCP servers.
