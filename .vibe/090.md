# Task 090: Refactor cmd entrypoint

## Goal

Consolidate the three entrypoint packages (`internal/cmd`, `internal/servercmd`, `internal/workercmd`) under a single directory `internal/cmd` with subpackages `cli`, `server`, and `worker`, so that all binary entry logic lives under one tree and is easier to navigate.

## Context

- **Current layout**
  - `internal/cmd` — CLI/TUI (Cobra root, version, print mode, TUI); used only by `cmd/buildmax/main.go`.
  - `internal/servercmd` — server startup (RunServer); used only by `cmd/buildmax-server/main.go`.
  - `internal/workercmd` — worker run (RunWorker, ErrAlreadyClaimed); used only by `cmd/buildmax-worker/main.go`.
- **Binaries**: `cmd/buildmax`, `cmd/buildmax-server`, `cmd/buildmax-worker` each have a thin `main.go` that initializes logging, parses flags, and calls one function from the corresponding internal package.
- **Conventions**: AGENTS.md describes `internal/cmd` as “Cobra root, flags, version; prompt/TUI runners”; `internal/servercmd` and `internal/workercmd` as startup for server and worker. Single language (Go), no new dependencies.

## In scope

1. **New directory layout under `internal/cmd`**
   - `internal/cmd/cli` — current `internal/cmd` code (root.go, version.go, print.go, tui.go, setup.go, root_test.go). Package name: `cli`.
   - `internal/cmd/server` — current `internal/servercmd` code (run.go, run_test.go). Package name: `server`.
   - `internal/cmd/worker` — current `internal/workercmd` code (run.go). Package name: `worker`.

2. **Package renames and moves**
   - Move all files from `internal/cmd` into `internal/cmd/cli`; change `package cmd` to `package cli`. Preserve exported symbols: `NewRootCommand`, `Version` (and any used by tests).
   - Move all files from `internal/servercmd` into `internal/cmd/server`; change `package servercmd` to `package server`. Preserve `RunServer` and test types.
   - Move all files from `internal/workercmd` into `internal/cmd/worker`; change `package workercmd` to `package worker`. Preserve `RunWorker` and `ErrAlreadyClaimed`.

3. **Update entrypoints**
   - `cmd/buildmax/main.go`: import `buildmax/internal/cmd/cli`, call `cli.NewRootCommand()`.
   - `cmd/buildmax-server/main.go`: import `buildmax/internal/cmd/server`, call `server.RunServer(ctx, port)`; update `workercmd.ErrAlreadyClaimed` reference if any (there is none in main; worker binary uses it).
   - `cmd/buildmax-worker/main.go`: import `buildmax/internal/cmd/worker`, call `worker.RunWorker(ctx, *chatRunID)`, use `worker.ErrAlreadyClaimed` for exit code handling.

4. **Remove old packages**
   - Delete the directories `internal/servercmd` and `internal/workercmd` after moves. The previous `internal/cmd` is replaced by `internal/cmd/cli` (no leftover `internal/cmd` package at top level).

5. **Build and tests**
   - `go build ./...` and `go test ./...` must pass. No behavior change beyond import paths and package names.

## Out of scope

- Changing behavior of CLI, server, or worker.
- Adding new subcommands or flags.
- Refactoring logic inside cli/server/worker (e.g. splitting root.go); that stays for a future task.
- Updating AGENTS.md or design docs (can be done in a follow-up).

## Deliverables

- New packages: `internal/cmd/cli`, `internal/cmd/server`, `internal/cmd/worker` with code moved and package names updated.
- Updated `cmd/buildmax/main.go`, `cmd/buildmax-server/main.go`, `cmd/buildmax-worker/main.go` imports and calls.
- Removed `internal/servercmd` and `internal/workercmd` directories.
- All existing tests retained and passing.

## Acceptance criteria

- [ ] `internal/cmd/cli` exists and contains the former `internal/cmd` code with `package cli`; `NewRootCommand` and `Version` are exported and used by `cmd/buildmax`.
- [ ] `internal/cmd/server` exists and contains the former `internal/servercmd` code with `package server`; `RunServer` is used by `cmd/buildmax-server`.
- [ ] `internal/cmd/worker` exists and contains the former `internal/workercmd` code with `package worker`; `RunWorker` and `ErrAlreadyClaimed` are used by `cmd/buildmax-worker`.
- [ ] `internal/servercmd` and `internal/workercmd` are removed.
- [ ] `go build ./...` succeeds.
- [ ] `go test ./...` succeeds (including `internal/cmd/cli`, `internal/cmd/server` tests).
