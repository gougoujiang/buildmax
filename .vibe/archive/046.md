# Task 046: Create new workspace

## Goal

Allow users to create a new workspace via the API and portal, so they are no longer limited to the auto-created "Default" workspace.

## Context

- **Workspace model** already exists in `internal/store/store.go` — `Workspace{ID, WorkspaceID, OwnerUserID, Name, CreatedAt}`.
- **WorkspaceStore interface** (`internal/store/store.go`) currently has `EnsureDefaultWorkspaceForUser`, `ListWorkspacesByOwner`, `WorkspaceBelongsToUser` — no create method.
- **API** exposes `GET /api/workspaces` in `internal/server/workspaces.go` (list only, JWT-authed). No `POST` endpoint exists.
- **Portal TopBar** (`portal/src/components/TopBar.tsx`) already renders a "+ New" button when `onNewWorkspace` is provided, but `App.tsx` does **not** pass `onNewWorkspace` — the button is invisible.
- **Portal api.ts** has no `createWorkspace` function. Mock data has one (`portal/src/data/mockData.ts`) but it's unused when authenticated.
- **Existing pattern**: `createProject` in the store, server handler, and portal API is the reference pattern for this task (JSON POST body with `name`, returns the created entity with `201 Created`).
- **Conventions**: snake_case JSON keys, singular table name, UUID public IDs, JWT auth, workspace dir created on disk.

## "Create workspace" (this task)

For this task, "create workspace" means:

1. Add a `CreateWorkspace` method to `WorkspaceStore` — inserts a new workspace row with a UUID, owner, and name.
2. Add a `POST /api/workspaces` handler — authenticates via JWT, validates the name, calls the store, creates the workspace directory on disk, and returns the new workspace.
3. Add a `createWorkspace` function to the portal API client and wire the existing TopBar "+ New" button so it calls the API, refetches workspaces, and navigates to the new workspace.

We are **not** yet implementing:

- Workspace rename or delete
- Workspace settings or description field
- Workspace sharing / multi-user access

## Deliverables

1. **`internal/store` — CreateWorkspace**
   - Add `CreateWorkspace(ctx context.Context, userID, name string) (*Workspace, error)` to `WorkspaceStore` interface.
   - Implement on `*Store`: generate UUID, set `OwnerUserID`, `Name`, `CreatedAt`, insert row, return the created workspace.

2. **`internal/server/workspaces.go` — POST handler**
   - Add `createWorkspaceRequest` struct: `Name string \`json:"name"\``.
   - Add `createWorkspaceHandler` on `*Server`:
     - `requireAuth` for JWT.
     - Decode JSON body; validate `name` is non-empty.
     - Call `WorkspaceStore.CreateWorkspace`.
     - Create workspace directory on disk via `os.MkdirAll(filepath.Join(config.WorkspacesDir(), workspaceID), 0755)`.
     - Return `201 Created` with `WorkspaceResponse`.
   - Register `POST /api/workspaces` route in `server.go`.

3. **`portal/src/lib/api.ts` — createWorkspace function**
   - Add `createWorkspace(body: { name: string }, token: string): Promise<ApiWorkspace>`.
   - POST to `/api/workspaces` with JSON body and Bearer token.

4. **`portal/src/App.tsx` — wire onNewWorkspace**
   - Add a `handleNewWorkspace` function: prompt for name, call `createWorkspace`, refetch workspaces, navigate to the new workspace.
   - Pass `onNewWorkspace={handleNewWorkspace}` to `AppShell` / `TopBar`.

5. **`portal/src/components/AppShell.tsx` — pass onNewWorkspace through**
   - Accept `onNewWorkspace` prop and forward it to `TopBar`.

## Out of scope (for later)

- Workspace rename / update
- Workspace delete (and cascade to projects/tasks/files)
- Workspace description or metadata fields
- Workspace member / sharing management
- Name uniqueness constraint (users can have multiple workspaces with the same name for now)

## Acceptance

- [ ] `POST /api/workspaces` with `{"name": "My workspace"}` returns `201` with the new workspace (id, name, owner_user_id, created_at).
- [ ] `POST /api/workspaces` without auth returns `401`.
- [ ] `POST /api/workspaces` with empty name returns `400`.
- [ ] New workspace appears in `GET /api/workspaces` list after creation.
- [ ] Workspace directory is created on disk under `WorkspacesDir()/<workspace_id>/`.
- [ ] Portal "+ New" button in TopBar is visible and functional: prompts for name, creates workspace, navigates to it.
- [ ] `go build ./...` and `go test ./...` pass.
