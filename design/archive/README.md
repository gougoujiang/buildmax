# Archived Design Docs

This directory contains older or superseded design documents kept for reference.

Typical reasons a doc is archived:

- it describes a product model that has since changed
- it reflects a completed migration path that is no longer the active architecture
- it documents implementation history that is still useful, but is no longer a good current entry point

Use these docs for historical context, not as the default source of truth for the current product.
