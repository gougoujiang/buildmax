- Working a space issue locally moved from the `buildmax --issue <id>` flag to
  the `buildmax issue start <id>` subcommand, alongside `issue list`, `show`, and
  `status`. It takes the same run flags as `buildmax` itself (`-p`, `--model`,
  `--workspace`, and so on).
