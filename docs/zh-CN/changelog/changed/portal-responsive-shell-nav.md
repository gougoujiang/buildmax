- Portal 的窄屏壳层(大致为手机宽度的窗口)现在显示一个紧凑头部,包含当前
  Space、页面标题和一个菜单按钮,点击后在可访问的覆盖式抽屉中展开完整导航,
  而不再把侧边栏挤压进页面正文。Portal 中的对话框——包括侧边标签页表单,窄屏
  下改为可用方向键切换的水平标签条——现在会捕获键盘焦点、在关闭时把焦点还给
  打开它的控件,并在窄屏上呈现为全高的表单页。Chat、Issues、Issue Detail 与
  Task Detail 在窄屏下也会重新排布:对话串与输入框不再因固定的两侧外边距而
  被压缩到只剩很窄的宽度,Task 头部的操作按钮会换行到标题下方而不是把标题挤
  掉,主要操作按钮也满足 44px 的最小可点击面积。Workspace Files 在窄屏下现在
  只显示当前文件夹的内容或选中的文件二者之一,并配有"返回"操作,而不再把固
  定宽度的文件夹树挤压在窄到难以阅读的内容旁边;Artifacts、管理后台列表
  (Administrators、Accounts、Spaces、Models、Plugins)与 Space 成员行在窄屏
  下会重新排布为堆叠布局,而不是把多个条目挤成含糊不清的一行;Run 的工具路
  径与 token 数量现在会在自己所在的行内横向滚动,而不再被省略号截断。
